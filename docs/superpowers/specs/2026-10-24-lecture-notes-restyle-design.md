# LexiScan「教授讲义」视觉迭代设计文档

日期：2026-10-24
状态：待用户批准
前置讨论：`.superpowers/brainstorm/` 中四轮视觉选型（基调 / 主页布局 / 结果页画框 / 字体），用户逐项选定。

## 一、意图与动机

LexiScan 当前是「暖橙拟物 + 小狐狸 IP」风格。本轮迭代做三件事：

1. **移除小狐狸 IP 形象**——所有界面不再出现吉祥物。
2. **整体界面风格切换为「教授手写讲义」**——米色讲义纸上的蓝黑钢笔字，照片像标本一样装裱在纸上，配手写标注。
3. **最近识别结果直接展示到主页**——从"上下翻页一次看一张"改为"生词表一眼看多行"。

为什么：让 App 从"可爱陪伴工具"转向"认真治学的笔记本"，视觉主题与背单词的学习场景更一致。

## 二、目标 / 非目标 / 反目标

**目标**

- G1 全应用移除小狐狸：组件、资源、界面引用、README 描述。
- G2 全局色彩与质感系统换成蓝黑讲义纸（米色横线纸底、蓝黑墨、红笔重点）。
- G3 主页改为：手写感标题 + 虚线手绘"拍一拍"入口 + **生词表**（最近 5 条，一行一词）。
- G4 结果页改为**图钉双线框**装裱识别照片，信息手写排布。
- G5 打包英文手写字体 Caveat（开源 OFL，约 200KB），用于英文单词、音标、例句、英文 UI 文案。
- G6 撕拉动画**原样保留**（代码与交互不动），仅随主题调整周边配色。
- G7 **词性字段贯通**（用户选定）：DeepSeek 提示词扩展返回中文词性，解析链路与 Room 表新增字段，识别结果页与历史详情页均显示；主页生词表行不显示（保持行紧凑）。

**非目标**

- 识别工作流原则上不动（U2-Net / SiliconFlow 不动）。唯一例外是 G7 词性贯通：DeepSeek 仅扩展提示词输出、Room 仅新增一列；两者其余部分不动。
- 不做暗色模式适配（本轮强制浅色，见 5.7）。
- 不改各页面信息架构与导航关系（HistoryListScreen / HistoryDetailScreen 仅换肤）。
- 不新增功能。

**反目标（出现即算失败）**

- 小字信息（音标、时间、置信度）因纸纹背景或字重变细而不可读。
- APK 体积因此轮增加超过 1MB。
- 主页一屏需要滚动超过一屏半才能看全生词表与拍照入口。

## 三、约束

- Jetpack Compose + Material3，Kotlin，现有工程结构不动。
- Compose 无原生虚线边框，需 `drawBehind` + `PathEffect.dashPathEffect` 实现手绘虚线框。
- 中文字体不打包（用户已选定系统字体方案），规避中文字库体积与版权问题。
- Caveat 需放 `res/font/`，通过 `FontFamily(Font(R.font.caveat))` 引入。
- 主页生词表数据源与现有 `HomeScreen(history: List<RecognitionRecord>)` 一致，`take(5)` 即可，无新查询。

## 四、方案权衡（用户已逐项选定）

### D1 纸墨基调 → 选定：A 蓝黑备课笔记

| 候选 | 取舍 |
|------|------|
| **A 蓝黑备课笔记（选）** | 蓝黑钢笔 + 浅横线纸，音标用红笔。对比度好、层次清楚、最耐看 |
| B 深棕旧纸 | 怀旧感最强，但对比度低，信息多时吃力 |
| C 黑墨红批 | 红色占比过高，看久了闹 |

### D2 主页最近结果形态 → 选定：B 生词表

| 候选 | 取舍 |
|------|------|
| A 标本墙 | 2–3 张照片并排，一眼看全，但放不下音标/例句 |
| **B 生词表（选）** | 一行一词：小照片+单词+音标+中文+时间+发音。信息最全，复习效率最高 |
| C 横滑胶卷 | 照片更大，但第三张在屏外，"直接展示"打折 |

### D3 结果页画框 → 选定：C 图钉双线框

| 候选 | 取舍 |
|------|------|
| A 胶带标本贴 | 手作感最强，但画框感弱 |
| B 手绘描边框 | 最贴"手写画框"字面，但与主页横线纸叠在一起时线条偏多 |
| **C 图钉双线框（选）** | 白衬纸 + 双线细框 + 红图钉，最工整，博物馆标本感 |

### D4 字体 → 选定：B 系统黑体（中文）+ Caveat（英文）

| 候选 | 取舍 |
|------|------|
| A 霞鹜文楷 + Caveat | 手写感最完整，但中文字库 2–4MB 且小字号可读性有风险 |
| **B 系统黑体 + Caveat（选）** | 只有英文手写，零中文字库成本，可读性最好 |
| C 霞鹜文楷 + Patrick Hand | 同 A 的中文问题 |

## 五、已决定的设计细节

### 5.1 色彩系统（改 `Theme.kt`）

| 用途 | 旧 | 新 |
|------|-----|-----|
| 页面背景 | `warmBg #F3E9DD` 暖米色 | `paperBg #F6F0DF` 米色讲义纸 |
| 纸面横线 | 无 | `rgba(90,110,150,.11)` 重复竖向条纹，行距约 33dp（用 Canvas/drawBehind 画，不随内容滚动错位——**固定在页面背景上**） |
| 正文墨色 | `warmTextPrimary #3E342F` | `inkBlue #2C3E5D` 蓝黑墨 |
| 强调/音标 | `warmOrange #FF7E5F` | `redPen #B03A2E` 红笔 |
| 次要文字 | `warmTextSecondary #8C7E74` | 墨色 65% 透明度 |
| 元信息 | `warmTextTertiary #BDB2AA` | 墨色 45% 透明度 |
| 卡片/标签底色 | 各色淡彩标签 | 统一白纸 `rgba(255,255,255,.5)` + 对应墨色文字 |
| 薄荷绿/淡紫/暖橙渐变 | 保留 | **全部退役** |

旧色值常量（`warmOrange` 等）保留定义但标记 `@Deprecated` 或直接更名映射到新色，避免散落引用编译失败；由实现者按最小改动原则处理。

### 5.2 字体（改 `Typography.kt` + `res/font/`）

- 下载 Caveat（Google Fonts，OFL）Variable Font，放 `res/font/caveat.ttf`。
- 新增 `val CaveatFamily = FontFamily(Font(R.font.caveat, FontWeight.Normal))`。
- 应用位置（英文内容与英文 UI）：App 标题 "LexiScan"、副标题英文、英文单词、音标、复数、英文例句、"Tap to Scan & Learn"、按钮英文文案。
- 中文一律 `FontFamily.Default`，不打包中文字体。
- 音标中的 IPA 字符（/ˈkɒfi/）Caveat 不含 IPA 字形，会回退到系统字体——可接受（回退字形颜色一致即可），不需处理。

### 5.3 主页 `HomeScreen.kt`

自上而下：

1. **讲义头**：左 "LexiScan"（Caveat 大字，墨色）；右上角日期"词汇讲义 · M月d日"（小字，墨色 65%）；下方细分隔线。
2. **拍照入口**：手绘虚线框（墨色虚线、不规则圆角感），内为 "📷 拍一拍 · 记个新词"（红笔）+ "Tap to Scan & Learn"（Caveat 小字）。保留按压缩放反馈。删除现在的橙色渐变拟物大卡。
3. **最近学的词**：区块标题行（左"最近学的词"，右红笔"全部 →"→ `onViewAllHistory`）。下方最近 **5** 条 `records.take(5)`，每行：
   - 左：缩略图约 40dp，白衬纸 + 微投影 + 轻微交替旋转（±1.5°，按 index 奇偶交替）；
   - 中：英文单词（Caveat 18–19sp 墨色）+ 音标（红笔 13sp）同行；下一行中文 + 相对时间（墨色 65%/45%）；
   - 右：🔊 发音按钮（红笔色，点击 `onAudioClick` 同结果页逻辑——**注意**：主页行点击目前是 `onHistoryItemClick` 进详情，发音为新增交互，实现时在行内直接调 `TtsManager.speak`，不进详情页）。
   - 行间用纸面横线天然分隔（不画额外分割线），行高约 56–64dp，点击整行进详情。
   - 删除现有 VerticalPager 翻页卡、页面指示圆点与"圆柱体卡片"。
4. **空状态**：无记录时显示一行手写感提示"还没有标本，拍第一个试试吧 →"（红笔），点击进相机。
5. 首页加载中仍用居中进度圈，色改墨蓝。
6. 删除 `LexiWelcomeSection` 与 `getGreeting` 的狐狸欢迎区；问候语逻辑删除（日期行取代）。

### 5.4 结果页 `RecognitionResultDialog.kt`

1. 背景改纸色 + 横线。
2. 删除顶部小狐狸 + 气泡 Row。
3. **图钉双线框**装裱区（替代顶部渐变背景区）：
   - 外层白衬纸框（白色，约 4dp padding）+ 外框 1.5dp 墨色实线 + 内框 1dp 墨色 55%（间距 3dp，双线）+ 柔和投影；
   - 顶部中央一枚红图钉（径向渐变圆 + 高光点，Canvas 绘制，约 16dp，压在框沿上）;
   - 框内容：`isSegmented=true` 时放分割透明图（`StickerImage` 的弹出 spring + 悬浮动画**保留**，尺寸缩至约 220–260dp 以适配框内）；否则放原图（`PlainImageDisplay` 改为 ContentScale.Fit + 白底）。
4. 信息区（框下方，居中，垂直排布）：英文单词（Caveat 34sp 墨色，`isEnglishValid=false` 时显示中文并保留灰色提示条，提示条样式改墨色系）→ 音标 + 🔊（红笔，同一行）→ 中文 + 词性（"咖啡杯 · 名词"，中文默认字体；词性来自 G7 新字段，为空时仅显示中文）→ 复数 + 置信度一行小字（墨色 45% 或红笔，取消彩色标签底）。收藏 ★ 按钮保留，放该行右侧，星形改红笔色。
5. 例句：白纸块（`rgba(255,255,255,.5)`）内英文（Caveat）+ 红笔下划线，下方中文翻译（65% 墨）。
6. 底部按钮：两个手绘虚线框按钮——"← 返回讲义"（墨色）与"再拍一个 →"（红笔虚线框）。保留按压缩放。文案改动同步 `strings.xml`。
7. 入场动画（fade + slide）保留。
8. 页面整体改为可上下滚动（`verticalScroll`，对齐 HistoryDetailScreen 的做法）：矮屏上装裱框 + 全部信息 + 按钮不被裁切；入场动画保留。

### 5.4bis 词性数据链路（G7，本轮唯一后端改动，用户选定）

- `DeepSeekService` 提示词 JSON schema 增加 `wordClass`（中文词性字符串，如"名词"）；dictionaryapi.dev 回退链路无词性，置 null。解析需向后兼容：旧格式无该键时不崩。
- `RecognitionViewModel` 新增 `wordClass` StateFlow（与 `plural` 等同级），传至结果页。
- Room：~~RecognitionRecord 增加 wordClass 列，Room version +1 并提供 Migration~~ **实现时核实**：工程持久化实际为 Gson + JSON 文件（非 Room，README 原描述有误）。`RecognitionRecord` 增加 `wordClass: String?` 字段即可，Gson 反序列化对缺失字段自动置 null，天然向后兼容，无需任何迁移。
- 展示：识别结果页（5.4.4）与历史详情页显示"中文 · 词性"；主页生词表行与历史列表行不显示。
- 旧记录词性为 null：详情页仅显示中文，不显示占位符。

### 5.6 历史页（`HistoryDetailScreen.kt` 内含 `HistoryListScreen`）

仅换肤 + 词性展示：背景纸色+横线、文字墨色系、列表行样式与主页生词表一致（复用同一行组件，抽成公共 Composable）。详情页大图按 5.4 的图钉双线框样式装裱，并在中文旁显示词性（G7，旧记录为空则不显示）。返回/收藏等交互不变。

## 六、留给实现者的决定

- 手绘虚线框的具体 Path 参数（抖动幅度、dash 周期）——以"肉眼像手画"为准，不追求毛笔质感。
- 图钉的最终绘制方式（纯 Canvas 或两层 Box + 渐变）与按压反馈。
- Room 迁移的具体写法（确认工程现有 fallback 策略后选择）。
- 主页行点击发音与进详情的手势边界（整行点击进详情，🔊 单独消费点击）。
- 横线纹理的性能实现（一次性 Canvas 缓存即可，无需 bitmap）。
- 主页生词表行组件与历史列表行的复用方式。
- 例句、复数为空时的留白节奏。
- Caveat 具体引入方式（variable font 单文件 vs 多字重静态）。
